# Daily close-path sensitivity v2

V1 is invalid for interpretation: known confirmation-overlap failures were censored to segment end, suppressing subsequent independent events; training/evaluation selection inconsistent as a result. Retain V1 for audit only. V2 changes only event termination: first confirmed next pivot violating direction or strict post-confirmation extreme timing terminates the event at that pivot's availability, categorized overlap exclusion. Missing next pivot is right-censored at segment end. Independent selection uses the same greedy chronology and training uses only events ended before the test start. All thresholds, targets, split, models, minimum training/evaluation count and improvement screen remain as in daily_close_path_spec.md. Reused history, exploratory only; no model promotion.
