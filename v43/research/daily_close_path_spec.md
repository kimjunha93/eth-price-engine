# V4.3 daily close-path sensitivity experiment (pre-run specification)

Exploratory, not untouched evaluation: 2023-01-01 onward, existing historical data reused. Separate Upbit ETH/KRW and Bitstamp ETH/USD. Input daily rows through 2026-11-26 UTC; valid OHLC; reset on missing dates. Close-only directional change thresholds 5,10,15,20,30,40,50%; close-based pivots, confirmed after reversal threshold. After confirmed low, next high/low/high must occur strictly after confirmation; otherwise censor. Targets normalized by low confirmation close (observable). End on third confirmation or data/gap censor. Nonoverlap greedy by event start including censored events, training events must end strictly before evaluation starts. Minimum 20 independent completed training examples. Compare flat, historical log-median (B1), actual historical medoid (L1 distance in log path), nearest-20 medoid by preceding close drawdown and confirmation overshoot (equal absolute log distance). Evaluate mean absolute percentage error across 3 legs and each leg, sample/censor counts, hold/fail counts. No tuning after evaluation; no promotion, no live probability. Improvement screen only: >=5% relative MAPE reduction versus B1 in both markets at same threshold with >=20 evaluated paths each. Close-only label is sensitivity test, not intraday extreme target. No new independent test available; subsequent live ledger required.
