# ATR extrema experiment v1 — exploratory
Use separate Upbit/Bitstamp daily OHLC through 2026-11-26 UTC, valid positive OHLC, reset on gaps. Wilder ATR14 (seed mean of first 14 true ranges per continuous segment). Scan fixed close reversal thresholds 5/10/15% and adaptive 2/3/4 ATR using ATR at each bar close, threshold frozen at most recent extreme (known at that close). All pivots close-based. Common evaluation events: confirmed 10% close pivot; predict next opposite 10% close extreme relative to confirmation close. Exclude next pivot if extreme predates event availability; terminate at its confirmation, otherwise right censor at segment end. Training only completed events strictly before current event, per direction, at least 20. Compare current close, historical median log target ratio, fixed 5/10/15% and ATR 2/3/4 state features using nearest 20 by absolute log distance in last confirmed pivot price relative to current close, plus binary last-pivot direction penalty of 1. Each model uses same event subset with all six causal states available. Evaluate 2023+ reused history, MAE percentage of actual extreme, median absolute percentage error, counts of censor/exclusion and sample sizes. Prefix test at 80% for each scan. No tuning; no promotion. Screen for at least 5% relative MAE improvement versus median in both markets and both directions, >=20 evaluated per cell. ATR states are predictors, not competing labels; results are not intraday extreme accuracy or live probabilities. Existing production unchanged.
