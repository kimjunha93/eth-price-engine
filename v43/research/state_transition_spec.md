# M7/M8 state transition experiment v1 — exploratory
Separate Upbit/Bitstamp valid daily OHLC through 2026-11-26, reset on gaps, causal close-confirmed directional change states 5/10/20/30/50%, Wilder ATR14 per contiguous segment. Origin every 20th daily close after 180 contiguous days, observation starts next bar, max 20 daily bars (evaluation cap only), fixed barriers upper +2 ATR14 / lower -2 ATR14 at origin, require positive lower. Same daily high/low touching both => ambiguous, never assume order; gap or end before resolution => censored. Classes up first, down first, no touch, ambiguous; retain censor separately, evaluate only fully observed classes. Independent nonoverlap origins by grid. State features latest confirmed 5/10/20/30/50% pivot direction and log pivot/anchor; all states required across compared models. Train only events with end strictly before origin; 2023+ reused history; minimum 20 training. B1 empirical class frequency with Laplace add-one; B2 zero-drift log-return resampling: last 180 contiguous daily close log returns, subtract training-window mean, 256 deterministic circular block paths (5-day blocks, four blocks per path, fixed LCG seed 20261127 reset each origin); use simulated close extrema only, report proxy mismatch vs OHLC labels and retain 4-class smoothing; M7 nearest 20 on 10% state (absolute log distance plus direction mismatch 1), M8 nearest 20 on all five states (mean same distance), same smoothing. Evaluate multiclass Brier sum, natural log loss, argmax accuracy (tie in up/down/no/ambiguous order), confusion and class counts, per market; prefix causal pivot tests at 80%. Screen only if >=30 evaluated per market and >=5% Brier AND log loss improvement over B1 in both markets; no promotion or calibrated live probabilities without untouched data. No forced long-term path or claim of full-cycle transitions; next barrier is proxy for state change. All target distances and evaluation caps fixed ex ante, not live targets.
